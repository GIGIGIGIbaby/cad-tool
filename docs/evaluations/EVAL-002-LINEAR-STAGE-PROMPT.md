## 需求（这就是全部输入）

设计一台**桌面自动化用的单轴电动直线滑台**，水平安装在桌面或铝型材上：

1. **有效行程 ≥ 200 mm**。
2. **负载**：滑块上承载 ≤ 2 kg 的工件，低速（≤ 50 mm/s），不要求高精度，但滑块运动不应晃动、卡滞。
3. **驱动**：一台 NEMA 17 步进电机。传动方式（丝杆、皮带等）由你决定，并在设计文档中说明理由。
4. **导向**：方式由你决定（光轴 + 直线轴承、直线导轨等）。
5. **滑块顶面**：可用安装面 ≥ 60 × 60 mm，带 M4 安装孔阵列。
6. **外形上限（行程 200 时，含电机）**：长 ≤ 450 mm，宽 ≤ 110 mm，高 ≤ 75 mm。
7. **安装**：底部能用螺钉固定到桌面/型材，需有安装孔。
8. **外购件**（电机、轴承、丝杆/皮带轮、光轴/导轨、联轴器等）必须按**真实标准尺寸**建模为简化占位体（外形、配合面、安装孔位正确即可，不要螺纹细节）。螺钉可以不建模，但对应孔必须存在且尺寸合理。
9. **自制件**要能加工：选择 CNC 铝件或 3D 打印（可混用），并按工艺给出合理壁厚。

## 必须满足的建模约定（评测将依赖它们）

- 用一个 `Spreadsheet`（对象名任意），其中必须有这两个别名：
  - `Stroke`：有效行程，初始 200。
  - `CarriagePos`：滑块位置，取值 0 … `Stroke`，0 为一端极限、`Stroke` 为另一端极限。
- 修改 `Stroke` 后，**整个装配必须随之更新**（底座、导向件、丝杆/皮带、端座等长度与位置），不能要求手工再改其它数。
- 修改 `CarriagePos` 后，滑块及随之运动的零件一起移动，固定件不动。
- 每个零件是**独立的实体对象**（`PartDesign::Body` 或 `Part` 特征均可），名字清晰；脚本里用 `cad_outputs` 列出所有交付零件。
- 在 `CarriagePos = 0` 和 `CarriagePos = Stroke` 两个极限位置，任意两个零件之间**不得有体积干涉**（允许面接触；名义配合面建成相等尺寸即可）。

## 交付物

1. `notes/design.md`：需求分析；至少两种方案对比与选择理由；载荷路径（力从负载到桌面怎么传）；关键尺寸表；BOM（外购件型号 + 关键尺寸 + 数量，自制件 + 工艺）；已知风险与未做的验证。
2. `src/main.py`（可拆分模块）：原生 FreeCAD 参数化脚本。
3. `models/main.FCStd`，以及 STEP 导出（`run --step`）。
4. 你自己做的验证：至少包括两个极限位置的两两干涉检查、外形尺寸、行程。把检查方法和结果写进 `notes/verification.md`；看过的渲染图写下你看到了什么。
5. **两次提交**：
   - 第一次：`Stroke = 200` 的完整设计。
   - 第二次：只修改源参数把 `Stroke` 改成 **300**，重新运行、验证、提交。（300 时外形长度上限不适用，但其它要求仍然适用。）
