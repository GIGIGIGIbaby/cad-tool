## 需求（全部输入）

设计一台**桌面 XY 十字滑台**（两轴叠放：上层轴整体装在下层轴的滑块上），用于桌面点胶/检测平台：

1. **行程**：X ≥ 150 mm，Y ≥ 150 mm。
2. **负载**：顶部平台承载 ≤ 3 kg，低速（≤ 30 mm/s），运动平稳不晃。
3. **驱动**：每轴一台 NEMA 17 步进电机；传动、导向方式自选并说明理由。
4. **顶部工作台**：可用面 ≥ 100 × 100 mm，带 M5 螺孔阵列。
5. **外形上限**（初始行程、两轴都在任意位置时的扫掠包络均须满足，含电机）：X 向 ≤ 420 mm，Y 向 ≤ 420 mm，高 ≤ 130 mm。
6. 底座能用螺钉固定到桌面。
7. 外购件按**真实标准尺寸**建简化占位体（外形、配合面、安装孔位正确），螺钉可不建模但孔必须存在。
8. 自制件可加工（CNC 铝 / 3D 打印，自选），壁厚合理。

## 必须满足的建模约定（评测依赖）

- 一个 `Spreadsheet`，别名：`StrokeX`、`StrokeY`（初始 150）、`PosX`（0…StrokeX）、`PosY`（0…StrokeY）。
- 改 `StrokeX` / `StrokeY` 后整个装配随之更新；改 `PosX` 后下层滑块及其上所有零件（包括整个上层轴）一起移动；改 `PosY` 后只有上层滑块及工作台移动。
- **保存的 FCStd 重新打开后**，只改表格 + recompute 就必须生效（评测会在没有你源码的环境里打开文件验证）。
- 每个零件是独立实体对象，名字清晰，`cad_outputs` 列出全部。
- 在 (PosX, PosY) ∈ {0, Stroke}² 四个角位置，任意两零件之间无体积干涉（面接触允许）。
